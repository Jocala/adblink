adbLink Main Screen

The upper left devices table displays three columns, device description, IP address and connection status. Each row of the table represents one record in the database. This table is sortable by column. Initially empty, it's filled by adding Android devices to the database via the new button.

Immediately to the right of the table are a grid of six buttons:

Connect (selected row)
Disconnect (selected row)
New (add record/row)
Edit (selected row)
Delete (selected row)
Clear: Clear Adhoc IP

Below the grid of six buttons is the Ad hoc IP field. Here you can enter the IP or domain address of a device "on the fly". When you make a connection via this method, a record with the description "Ad hoc" is added to the table.

adblink offers two views, Kodi and Android. The menu choices and button layout vary depending on which layout you choose. You can specify the starting layout via the preferences menu or you can switch layouts at will via the utility menu function Switch View

In the section below the device table and edit/connection buttons you will see a grid of buttons, sixteen buttons for the Kodi view or twelve for the Android view.
