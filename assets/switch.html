Switch View

Switch View toggles between enabling adblink's Kodi features or disabling them, Kodi View or Android View. If you're using adblink for a device that doesn't have Kodi, Android View will hide Kodi-related menus and buttons.

You can also set your preferred starting view via preferences

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
