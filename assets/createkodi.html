Create kodi_data

On Android 11+ and Fire OS 8, scoped storage prevents ADB from accessing Kodi's data at /sdcard/Android/data/org.xbmc.kodi/files/.kodi. This function relocates Kodi's data to /sdcard/kodi_data/ and creates the xbmc_env.properties file that tells Kodi where to find it at startup.

What it does

  1. Stops Kodi if it is running on the device.
  2. On Android 11+, Kodi should ask for MANAGE_EXTERNAL_STORAGE permission at first run. If it doesn't, grant it manually via the device's Settings → Apps → Kodi → Permissions.
  3. Removes any existing /sdcard/kodi_data/ directory.
  4. Creates /sdcard/kodi_data/package/files/.kodi (where package is org.xbmc.kodi by default).
  5. Writes /sdcard/xbmc_env.properties with the line: xbmc.data=/sdcard/kodi_data/package/files. Kodi reads this file at startup to locate its data area.

When to use

  • Setting up a new device with scoped storage enabled.
  • After restoring a backup to a scoped-storage device (adblink creates this automatically during restore).
  • If Kodi cannot find its data after you have enabled scoped storage.

After creation

Kodi's data now lives at /sdcard/kodi_data/ instead of the inaccessible Android/data/ path. You can now back up, restore, and edit Kodi files normally. See Scoped Storage for more details.
