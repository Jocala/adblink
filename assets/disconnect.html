Disconnect

The Disconnect button (Ctrl+E) disconnects a connected network device.

Usage

Select a connected device in the device table and click Disconnect. A confirmation dialog appears before disconnecting. After confirmation, adb disconnect <ip> is issued and the device status changes to "Disconnected".

Notes

  • Only network-connected devices can be disconnected — USB connections are handled automatically.
  • If the device is already disconnected, a warning is shown.
  • Double-clicking a "Connected" row in the device table also triggers Disconnect.
