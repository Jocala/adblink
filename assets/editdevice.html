Edit Device

The Edit button (Ctrl+W) opens the Device Record dialog pre-filled with the selected device's settings so you can modify them.

Usage

Select a device in the device table and click Edit. The Device Record dialog opens with the device's existing values. Make changes and click Save to update the database.

Fields

  • Description — a friendly name for the device
  • IP Address — network address or USB serial
  • Port — ADB port
  • USB Connection — whether the device connects via USB
  • Package Name — Kodi package name
  • Data Root — device data root path
  • File Path — Kodi data subdirectory
  • Pull Directory — local directory for pulled files
  • Scrcpy Args — optional scrcpy arguments

Notes

  • The description must not be empty.
  • The Kodi-specific fields (Package Name, Data Root, File Path) are available in Kodi view only.
