Device Offline

If your device shows as "offline" in the device table, try the following troubleshooting steps:

Toggle ADB Debugging

Go to Settings → Developer Options on your device. Turn USB debugging off, then back on. This often resolves the offline state.

Revoke USB authorizations

In Developer Options, select Revoke USB debugging authorizations and confirm. Then reconnect the USB cable and accept the authorization prompt on the device.

Delete old ADB keys

On your computer, delete (or rename) the .android/adbkey and .android/adbkey.pub files in your home directory. Reconnect the device and accept the authorization prompt.

Fire TV: Disable FireStarter

FireStarter is no longer compatible with recent Fire OS versions and will cause the "offline" state. Force stop FireStarter in Settings → Applications → Manage Installed Applications, then toggle USB debugging off and on.

Wireless debugging (Android 11+)

On Android 11 and later, ensure Wireless debugging is enabled in Developer Options (not just USB debugging) when connecting over Wi-Fi. Use the pairing code shown on the device for the initial connection.
