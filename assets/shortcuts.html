Keyboard shortcuts

macOS: substitute Command (Apple) key for Ctrl

ADB Shell: Ctrl+A
Backup Kodi: Ctrl+B
Screen Capture: Ctrl+C
File Manager: Ctrl+F
Keypad: Ctrl+K
Console: Ctrl+N
Start App: Ctrl+O
Stop App: Ctrl+P
Restore Kodi: Ctrl+R
Scrcpy: Ctrl+S
Send text to device: Ctrl+T
Uninstall APK: Ctrl+U
Install APK: Ctrl+V
Connect selected device Ctrl+D
Disconnect selected device Ctrl+E
Add new device Ctrl+G
Edit selected device Ctrl+W
Delete selected device Ctrl+I
Clear ad hoc IP field Ctrl+J
Toggle display on/off: Ctrl+X
Toggle window/font size: Ctrl++

If you have questions or comments, please email jocala@jocala.com adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
