View Kodi Logs

Kodi keeps two logs: one for the current run and one for the previous run. They are named kodi.log and kodi.old.log.

Select Kodi → View Kodi logs to open the log viewer. The viewer shows the current log by default. Press Swap to toggle between the current and previous log. Press Copy to copy the log content to your clipboard for inclusion in support requests.

The same viewer is used for adbLink logs — see View adbLink Logs.

If you have questions or comments, please email jocala@jocala.com. adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
