Android only

ADB Server

The "Stop ADB" item in the Utility menu asks for confirmation, then stops the adb server, disconnecting all network devices.

Each device must be reconnected individually afterwards: select it and use Connect (or double-click its row). USB devices reappear on their own the next time the adb server starts.

To update the Status column without stopping anything, use Refresh ADB instead.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
