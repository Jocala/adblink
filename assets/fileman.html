File Manager

The File Manager is a dual-pane style dialog, reminiscent of Norton Commander or Midnight Commander. It allows users to open two separate folders simultaneously and perform operations such as copying, moving, renaming, deleting, creating directories, and editing files. File Manager supports intuitive drag-and-drop functionality, enabling users to easily move or copy files and folders between panes or to other compatible applications by dragging and dropping.

Navigate by clicking through the file hierarchy or by selecting a preset and clicking the go button. You can also type your location into the dialog and hit return or click the go button.

To use drag-and-drop, simply select a file or folder in one pane, drag it to the desired location in the other pane, and release to complete the action.

To copy a file from your computer to the Android device, simply select a file or folder on the PC, drag it to the desired location on the File Manager, and release to complete the action.

Drag and drop streamlines file management tasks and enhances usability, especially for users accustomed to graphical interfaces.

Right-click context menu

Copy: Copy item to opposite pane
Move: Move item to opposite pane
Rename: Rename item
Delete: Delete item(s)
Mkdir: Make new directory
Pull: Pull item(s) from device to PC
Edit text: Edit text file
New text: Create new text file
Home: Reset both panes to /sdcard/
Close: Close file manager

For drag-and-drop operations, compatibility depends on the target application or location. Some directories or external applications may not support drag-and-drop due to permissions or platform restrictions. Ensure that the target location is writable and compatible with File Manager's drag-and-drop feature.
