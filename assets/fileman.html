File Manager

The File Manager is a dual-pane dialog for browsing and managing files on your connected Android device. It provides full access to the device's filesystem, including /sdcard/, /storage/, and /data/local/tmp/.

Navigation

Use the Presets drop-down to jump to common locations (/sdcard/, /storage/, /data/local/tmp/, and Kodi data folders if available), then click Go. You can also type any path directly into the address bar and press Enter or click Go. Click through the folder hierarchy in either pane to navigate.

Right-click context menu

Right-click on a file or folder to access these operations:

  • Copy — copy selected item(s) to the opposite pane
  • Move — move selected item(s) to the opposite pane
  • Rename — rename the selected item
  • Delete — delete selected item(s)
  • Mkdir — create a new directory
  • Pull — copy selected item(s) from the device to your computer. If the initial pull fails, adblink retries via /data/local/tmp/ as a fallback.
  • Edit text — edit a text file on the device
  • New text — create a new text file on the device
  • Home — reset both panes to /sdcard/
  • Close — close the file manager

Drag and drop

Drag files between the two panes to copy or move them on the device. You can also drag files from your computer directly into a pane to push them to the device via adb push.

Known limitations

  • Files and directories whose names contain embedded double-quote characters (") cannot be edited, copied, renamed, deleted, or browsed.
  • Directories or files the ADB shell cannot list are silently hidden from the file listing (no error is shown).
  • The two panes share the window equally with no adjustable splitter handle.
