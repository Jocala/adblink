System Information

Select Utility → System information to display details about the currently connected device.

The dialog shows:

  • Architecture — CPU ABI (e.g. arm64-v8a, armeabi-v7a, x86_64)
  • Android version — Android API level
  • Device name — device model identifier
  • Device release — Android build version string
  • Manufacturer — device manufacturer
  • Battery level — current battery charge percentage
  • Scoped storage — whether the device uses scoped storage (Android 11+)
