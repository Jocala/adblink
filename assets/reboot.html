Android only

Reboot device

Reboots the connected device. Select a device in the device table, then choose one of the two items.

Reboot — reboots the device normally, via adb reboot.

Recovery — reboots the device into recovery mode, via adb reboot recovery.

Both items ask for confirmation first. After a network device is rebooted, adblink disconnects it and its status changes to "Disconnected"; a USB device stays in the table and reappears when it comes back.

Recovery mode

Whether the device exposes recovery depends on the hardware. Some devices bring adbd up while in recovery, in which case the status column reads "Recovery", ADB Shell still works, and the Reboot item is the way back to a normal boot. Others show a recovery menu that has to be driven with the device's own buttons, and adblink cannot get it out of that state.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
