Specify directories:
Pull directory. A global location where files "pulled" from the selected device go. This can be overridden at the device-level in the device's record.

APK directory. The default location where adblink looks for APKs to install

Backup directory. The default location where backups are saved. Restore looks here as well.

External adb directory. The directory where an external adb binary is located.
