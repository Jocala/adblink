General Preferences

Checkboxes

Check for updates at program start
Ask for Scrcpy arguments
Kodi view at startup

Scale and font sizes

Default scale: Small / Medium / Large
Large scale font: 14, 16, 18, 20
Medium scale font: 12, 14, 16, 18
Small scale font: 10, 12, 14, 16
File manager font: 12, 16, 18, 22

Terminal type

macOS: macOS Terminal or iTerm2
Linux: Gnome Terminal, XFCE4 Terminal, or KDE Konsole
Windows: N/A

Directory paths

Pull directory — Global folder where files pulled from the device are saved. Can be overridden per-device in the device record.
APK directory — Where adblink looks for APK files to install.
Backup directory — Where backups are saved and restored from.
External ADB — Path to a custom adb binary. Leave blank to use the adb bundled with adblink.

Dialog buttons

Cancel — discard changes
Updates — check for a new adblink version
OK — save and close

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
