The "Push Remote" button installs an xml file defining a remote for Kodi.

Any xml file installed with this function is installed to userdata/keymaps/keyboard.xml.

Please note that Kodi MUST have been run for the first time before using this function.

If you have questions or comments, please email jocala@jocala.com. adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
