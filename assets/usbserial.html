USB Device Naming

When adblink automatically detects a new USB-connected Android device, it creates a device record using the device's USB serial number as the description. For example, a device with serial G0909N1823520BPE will appear in the device table with that exact identifier.

If a serial number happens to conflict with an existing device description, adblink appends a number to make it unique. For example, if "ABC123" is already in use, the new record will be named "ABC123-2", "ABC123-3", and so on.

You can rename any device at any time by selecting it and pressing Edit (Ctrl+W). The serial number stored in the daddr field remains unchanged — only the display name is updated.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
