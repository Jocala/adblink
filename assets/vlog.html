View adbLink Logs

adbLink keeps two logs: one for the current run and one for the previous run. They are named adblink.log and adblink.old.log.

Select File → View adbLink logs to open the log viewer. The viewer shows the current log by default. Press Swap to toggle between the current and previous log. Press Copy to copy the log content to your clipboard for inclusion in support requests.

The same viewer is used for Kodi logs — see View Kodi Logs.

If you have questions or comments, please email jocala@jocala.com. adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
