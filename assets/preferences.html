adbLink Device Record

Other than device settings specific to your system, there is little required for a basic connection between your media device and adbLink.

If you are connecting your device via a USB cable, plug in the cable and enable USB debugging on the device. adbLink polls every three seconds and will auto-detect the device, adding it to the device table. You are now ready to use other adbLink features such as installing Kodi, doing backups, etc.

If you are connecting your device via IP address, enter the IP address into the "Ad Hoc IP" text entry field, then press "Connect". The device will appear in the device table. You are now ready to use other adbLink features such as installing Kodi, doing backups, etc.

You may also create a record for your device. Records allow you to maintain multiple media devices, without the need to remember their IP addresses, and allow you to reference devices by a descriptive name. Using records you can also specify custom Kodi locations on your system, such as sd cards or usb thumb drives. Device records are optional for Kodi systems, but required for Kodi forks such as SPMC.

Adding a device record with adbLink

1. Connect to your device, using the instructions above.

2. Press the "New" button. This will bring up a blank device record screen.

3. Fill in the device fields manually, or type/paste the USB serial number or IP address into the Address field.

Record data fields:

Description: A description for the device, e.g. Living room TV. A description must be unique. You couldn't have two devices named "Living room TV".

Address. The address of this new device. It can be an IP address or a USB serial number. If you've selected a non-Android OS, this field is inactive.

Kodi Partition: For Android the default is /sdcard/ For other OSes, this field is inactive.

Media Center Package name: For Android the default is org.xbmc.kodi For other OSes, this field is inactive.

File Path: This the path to Kodi's data folder. For Android it defaults to /files/.kodi, on other OSes the path changes. When you choose the OS, this field is filled in with a reasonable default. You can also use the File Path button to browse your local computer for the Kodi data area.

Pull Folder: This will allow you to set the file path for files copied from your Android device to be sent to.

USB checkbox. Check this for USB-connected devices

IP address port: Default is 5555.

Scoped storage checkbox. Check this if your device enforces scoped storage (Android 11+).
