About adblink

adblink is a companion program for any device running Kodi. adblink allows easy maintenance of Kodi: edit Kodi's XML files, make backups of Kodi's data, restore those backups or clone new installations from your backups. For Android Kodi, adblink installs (sideloads) apps to your device without the bother of installing the Android SDK, as well as offering other Android-only functionality.

About Dialog

The About dialog shows the current adblink version number and includes a donation graphic that links to PayPal. Donations keep adblink's dedicated server running.

Select File → About adblink to open the dialog.
