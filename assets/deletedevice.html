Delete Device

The Delete button (Ctrl+I) removes a device record from the database.

Usage

Select a device in the device table and click Delete. A confirmation dialog asks "Delete <device>?". Click Yes to remove the record. After deletion, adblink runs adb disconnect to clean up any lingering ADB connection.

Notes

  • You cannot delete a device that is currently connected — disconnect it first.
  • Deletion is permanent and cannot be undone.
  • The device is removed from both the database and the device table.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
