New Device

The New button (Ctrl+G) opens the Device Record dialog to add a new device to the adblink database.

Fields

  • Description — a friendly name for the device (required)
  • IP Address — network address or USB serial
  • Port — ADB port (default 5555)
  • USB Connection — check if the device connects via USB
  • Package Name — Kodi package (default "org.xbmc.kodi")
  • Data Root — device data root path (default "/sdcard/")
  • File Path — Kodi data subdirectory (default "/files/.kodi")
  • Pull Directory — local directory for pulled files
  • Scrcpy Args — optional arguments passed to scrcpy

Notes

  • A duplicate description is not allowed — the database prevents it.
  • The Kodi-specific fields (Package Name, Data Root, File Path) are available in Kodi view only.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
