Backup Kodi

The Kodi Backup button backs up the contents of Kodi's .kodi folder on the connected device. Kodi must have been run at least once before using this function. Under Android, empty directories are not backed up.

Android 11+ / Scoped Storage

On Android 11 and later (including Fire OS 8), scoped storage restricts ADB access to /sdcard/Android/data/. If your device has the Scoped storage checkbox enabled in the Device Setup dialog, adblink handles this automatically:

  • Kodi data is relocated to /sdcard/kodi_data/ via the xbmc_env.properties file.
  • Backup pulls from kodi_data/ instead of the inaccessible Android/data/ path.
  • See Create kodi_data and Scoped Storage for setup details.

Partition selection

You will be prompted to choose where Kodi's data resides on the device:

  • /sdcard/ — default location for Android Kodi data.
  • External storage — if you have moved data to an SD card or USB drive, adblink lists all available external partitions.

Non-Android devices

adblink uses the default Kodi data location for the operating system (macOS, Linux, Windows). This can be overridden in the Device Setup dialog.

Kodi forks

If you are using a Kodi fork such as SPMC, change the package name and file path in the Device Setup dialog to match your software.
