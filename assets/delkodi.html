Kodi keeps everything it owns under a single data folder: settings, the media library databases, addons and their data, thumbnails, sources, favourites and log files. Deleting that folder resets Kodi to a fresh install without touching the application itself - Kodi stays installed and rebuilds the folder the next time it starts.

Select the device, then choose Kodi > Delete Kodi data. If Kodi is running on the device you are asked whether to stop it first; deleting under a running Kodi is not allowed, because Kodi rewrites files as it exits. adblink then shows the exact folder it found and asks for confirmation.

The folder reported is the one adblink resolves for that device - the location named in /sdcard/xbmc_env.properties if one exists, otherwise the scoped kodi_data path on Android 11 and later, otherwise /sdcard/Android/data/<package>/files/.kodi. The whole folder is removed, so the reset is complete and cannot be undone.

Use Backup first if there is anything worth keeping. To reset only part of Kodi, clear addons or userdata from the File Manager instead, and note that Delete thumbnails removes only the image cache.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
