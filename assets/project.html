Projectivy Launcher

This experimental function will download and optionally install the Projectivity launcher on your device.

This launcher has the ability to override your device's default launcher via Android's accessibility settings, if your OEM has not locked these settings down.

Tested and working with the Firestick 4KMax, Fire OS 8, release RS8145.3070N. It will NOT to work with any device running Fire OS 7. Accessibility settings are locked down in these devices.

If you have questions or comments, please email jocala@jocala.com. adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
