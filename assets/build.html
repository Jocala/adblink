Building and Packaging adbLink

adbLink uses CMake for building and CPack for packaging. The build process works on Windows, macOS, and Linux.

Build

cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

Package

cd build
cpack

This produces the platform-appropriate package in the build directory:

Windowsadblink-8.0-win64.exe   (NSIS installer)
macOSadblink-8.0-Darwin.dmg   (drag to install)
Linuxadblink-8.0-Linux.tar.gz   (extract and run)

The version number (8.0) is defined in CMakeLists.txt and is automatically reflected in all three package file names. The adbfiles directory (adb, aapt, busybox, fastboot, scrcpy) is bundled automatically into each package.

Windows Prerequisites
NSIS (Nullsoft Scriptable Install System) must be installed and makensis.exe must be on your PATH. Download from nsis.sourceforge.io.

macOS Prerequisites
No additional tools required. CPack uses the built-in DragNDrop generator to create the DMG.

Linux Prerequisites
No additional tools required. CPack uses the built-in TGZ generator.

If you have questions or comments, please email jocala@jocala.com. adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
