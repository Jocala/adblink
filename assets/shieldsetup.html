Android TV / Google TV Setup

adbLink is tested with the Nvidia Shield, Chromecast with Google TV, and other Android TV OS devices running Android 11 and later. Device menu labels may vary slightly between manufacturers and OS versions.

1. Enable Developer Options
Go to Settings → System → About (on some devices: Settings → Device Preferences → About).
Scroll down to Build and press the select button seven times. You will see a message that Developer Options are enabled.

2. Enable USB Debugging
Go to Settings → System → Developer Options.
Turn USB debugging ON. This is required even for Wi-Fi connections on most devices.

3. Enable Wireless Debugging (Android 11+)
In Developer Options, turn Wireless debugging ON. Confirm the dialog that appears.

Tap Wireless debugging to see details. You will see an IP address and port (e.g. 192.168.1.100:12345) and a pairing code. The pairing code is needed for the initial wireless connection.

From your computer, pair with the device using adbLink's console or a terminal:

adb pair 192.168.1.100:12345
Enter pairing code: 123456
adb connect 192.168.1.100:12345

After pairing, you can connect normally using adbLink's Connect button with the standard ADB port (5555).

4. Allow Unknown Apps
Go to Settings → Apps → Special app access → Install unknown apps. Enable permission for any file manager app you use. This allows sideloading applications such as Kodi.

5. Find Your IP Address
Go to Settings → Network & Internet. Select your Wi-Fi network to see your IP address (e.g. 192.168.1.101).

6. Connect via adbLink
For USB: plug your device into the computer. A dialog will appear on the device asking you to authorize. Check Always allow and confirm. adbLink will auto-detect the device within a few seconds.

For Wi-Fi (after wireless pairing): enter the IP address into the Ad Hoc IP field in adbLink and press Connect.

If you have questions or comments, please email jocala@jocala.com adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
