Ad Hoc IP

The Ad hoc IP field allows quick connection to a device by IP address without permanently adding it to the device database.

Usage

Enter the device's IP address in the field (placeholder shows "IP Address:port"). Add an optional port separated by a colon (e.g. 192.168.1.100:5555). If no port is given, 5555 is used by default.

Click Connect or press Ctrl+D. adblink creates a temporary device record with the description "Ad hoc" and connects to it. The "Ad hoc" record replaces any previous ad hoc entry each time.

Clear

Use the Clear button (Ctrl+J) or the Clear menu item to empty the field.

Notes

  • Port must be between 1 and 65535.
  • The temporary record uses default values for data root ("/sdcard/") and package name ("org.xbmc.kodi").
  • To make the connection permanent, edit the "Ad hoc" device record after connecting and give it a proper description.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
