Clear

The Clear button (Ctrl+J) clears the Ad hoc IP text field.

Usage

Click Clear or press Ctrl+J to empty the Ad hoc IP field so you can enter a different IP address.

This is a simple convenience action with no side effects — no database changes, no confirmation dialog.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
