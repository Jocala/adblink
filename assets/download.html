Download Kodi

The Kodi → Download Kodi menu function checks the Kodi website for the latest release, then downloads and installs the APK directly to your connected Android device.

How it works

  1. adblink connects to the Kodi release server and fetches the latest version number.
  2. A dialog asks you to choose an architecture:
    • ARM — 32-bit (most Fire TV devices, older Android devices)
    • ARM64 — 64-bit (Nvidia Shield, newer Fire TV, most phones/tablets)
    • Open in browser — opens the Kodi download page at https://kodi.tv/download/android for manual selection
  3. If you select ARM or ARM64, adblink downloads the APK and shows progress in the status bar.
  4. When the download completes, you can choose to:
    • Install — sideload the APK onto the connected device
    • Logfile — view download details in the log
    • OK — dismiss without installing

If you are unsure which architecture your device uses, see System Information.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
