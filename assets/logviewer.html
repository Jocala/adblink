Log Viewer

The Log Viewer displays both adblink logs and Kodi logs in a single dialog.

Accessing the Log Viewer

adblink logs  File → View adblink logs
Kodi logs  Kodi → View Kodi logs

adblink Logs

adblink keeps two logs: one for the current run and one for the previous run. They are named adblink.log and adblink.old.log.

Kodi Logs

Kodi keeps two logs: one for the current run and one for the previous run. They are named kodi.log and kodi.old.log.

Dialog Controls

Swap — toggle between the current log and the previous log.
Copy — copy the entire log content to the clipboard for inclusion in support requests.
Close — close the Log Viewer.

If you have questions or comments, please email jocala@jocala.com. adblink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
