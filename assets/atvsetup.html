Amazon Fire TV / Fire Stick Setup

adbLink is tested with Fire OS 7 and Fire OS 8 devices. These instructions apply to Fire TV Stick 4K, Fire TV Stick 4K Max, Fire TV Cube, and Fire TV Omni series.

Note: newer Fire TV devices (2023 and later) do not have USB ports. Connections are made via Wi-Fi only.

1. Enable Developer Options
From the Fire TV home screen, go to Settings → My Fire TV → About.
Highlight your device name and press the select button on your remote seven times. You will see a message that Developer Options are enabled.

2. Enable ADB Debugging
Go back to Settings → My Fire TV → Developer Options.
Turn ADB debugging ON.
If available, also turn USB debugging ON.

3. Allow Unknown Apps
In Developer Options, turn Install unknown apps ON. This allows you to sideload applications such as Kodi.

4. Find Your IP Address
Go to Settings → Network. Select your Wi-Fi network and press the Play/Pause button on your remote to see details. Make note of your IP address (e.g. 192.168.1.100).

5. Connect via adbLink
Enter the IP address into the Ad Hoc IP field in adbLink and press Connect. If this is your first connection, a dialog will appear on the Fire TV asking you to authorize. Check Always allow and confirm.

Wireless Debugging (Fire OS 8)
Fire OS 8 (Android 11) supports wireless debugging. If ADB over Wi-Fi is not working, go to Developer Options → Wireless debugging and turn it ON. Use the pairing code shown on screen with the adb pair command if prompted.

If you have questions or comments, please email jocala@jocala.com adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
