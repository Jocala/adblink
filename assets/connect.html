Connect

The Connect button (Ctrl+D) connects to a network device via ADB.

Usage

Select a device in the device table and click Connect. The device's IP address and port (default 5555) from the device record are used to issue adb connect <ip>:<port>.

States after connect attempt

  • Connected — device is reachable and ready for use
  • Offline — device was found but is in an offline state
  • Unauthorized — device rejected the connection; check for an authorization prompt on the device
  • Recovery — device has booted into recovery mode; adb shell works, but the normal Android app layer does not
  • Rescue — device has booted into rescue mode; adb shell works
  • Unable to connect — device is unreachable or refused the connection

A device in Recovery or Rescue is treated as connected: ADB Shell, Disconnect and the other device actions are available, and double-clicking its row disconnects it. Selection-sensitive features that need the running Android system, such as scrcpy or installing apps, will report their own failure from the device.

Notes

  • USB-connected devices cannot use Connect — they are auto-detected.
  • If the Ad hoc IP field has an IP address, Connect creates a temporary device record first, then connects.
  • Double-clicking a "Disconnected" row in the device table also triggers Connect.
